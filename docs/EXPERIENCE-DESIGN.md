# 学习体验与界面设计

2026-10-28 · 界面 v19

## v19 界面结构

按用户 2026-10-28 的明确要求，保留原来的米白、森林绿配色，以及原来的深色绿色体系。浅色背景 `#f3f5f1`、纸面 `#fffefa`、主色 `#315b46`、选中底色 `#eaf0e8`；不改变为蓝色主题。

- 导航统一为图标与文字，当前页面使用底部指示线。页面标题、辅助说明、搜索筛选、批量选择分层排列。
- 选词页的单词使用独立卡片，选中态同时展示勾选框、底色和边框；熟练度保持可编辑，辅助信息降低视觉权重。
- 宽屏将本次练习放在右侧，展示已选数量、可滚动的已选词列表、逐词移除、当前阅读主题、阅读与交流入口及设置链接。移除本次练习词不会删除词库单词或修改熟练度。
- 平板保留单列词卡与右侧练习区域；宽屏主列表达到合适宽度后改为双列。760 像素及以下使用底部操作栏，已选筛选仍可查看和调整本次用词。短横屏提供紧凑筛选与选词菜单。
- 阅读配置、交流表单、正文、释义、历史文章和设置共用一致的纸面、边框、字号与按钮层级。同步、保存、生成及交流沿用既有真实服务流程。

专项检查 `npm run test:studio` 覆盖原配色、长选词列表滚动、逐词移除及重开恢复、词库数据与等级不变，以及七种窗口尺寸下的操作入口。预览使用合成词库，保存在 `docs/previews/design/`；这些本地截图不代表正式宿主已经更新。

## 日常路径

在词库勾选单词，然后直接点击底部的「开始阅读」或「开始交流」。勾选就是本次用词，不再进入准备词组页面，也没有二次确认。阅读使用上次的文章配置，交流使用上次的话题、节奏和开场；想修改时进入对应设置页面。

## 页面分工

| 页面 | 主要任务 | 布局与操作 |
| --- | --- | --- |
| 词库 | 找词、勾选、直接开始 | 搜索和筛选在列表上方，分页在下方；宽屏右侧集中展示本次已选词、阅读主题和开始按钮，窄屏使用底部操作栏。录入新词是独立的次要按钮，和选择练习词分开。已选数量可切换为只看已选，跨页勾选保持一致。 |
| 阅读设置 | 按需修改文章 | 本次用词折叠展示；主题、篇幅直接显示，难度和句法折叠；可以继续上次阅读。无需在这里确认词组。 |
| 阅读 | 连续阅读、按需查词 | 正文优先；点词后先显示当前句子的词义，再显示一般释义与词典资料；关闭释义回到所选词。 |
| 英语交流 | 修改话题与开场、开始交流 | 一张表单依次放话题、节奏、开场和开始按钮；用词调整默认折叠；真实复盘接在交流之后。避免分散在两张卡片来回找按钮。 |
| 历史文章 | 找回和重读 | 搜索标题或主题，整张文章卡可点击；无匹配时可直接清除搜索。 |
| 学习设置 | 调整个人阅读体验 | 外观、词库间距、字号、行距与标词开关分组；即时预览，保存生效，取消恢复。 |

## 减少不必要的操作

- 普通手动录入的新词点击「保存到词库」一次完成。重复词涉及熟练度变化，图片识别可能需要校对，这两种情况才显示核对列表。
- 「帮我选」是可选快捷菜单，可以选中今天的词，或在当前已选词之外补充四个复习词，不会默认混入未勾选的词。
- 阅读/交流设置会记住；日常开始按钮不要求先打开设置。
- 已有待完成写作时明确显示「继续上次写作」或「查看写作进度」，继续的是冻结的原任务，不会悄悄替换其中的用词。
- 录入新词只保存到词库；是否用于本次练习由勾选决定。

## 横竖屏

- 宽屏主列表有足够空间时使用双列词条；右侧展示本次练习。平板采用单列词条与练习侧栏，760 像素及以下使用单列词条和底部两枚并列的开始按钮。
- 短横屏压缩顶部装饰，将筛选收进可展开面板；选词快捷操作移到底部数量菜单，设置入口保留在导航栏。列表和开始按钮同时可见，适配至 568×320。
- 竖屏未查词时正文占主要空间，查词后词义卡位于下方；短横屏使用正文和词义左右并排。
- 阅读设置和交流表单连续滚动，避免多个矮卡片各自滚动。
- 设置弹窗头尾固定，中间滚动；保留安全区、键盘焦点和减少动态效果支持。

## 保存与反馈

- 单词复选框先更新画面，再串行同步到词库服务；快速勾选和取消合并到最后的选择。开始阅读或交流会等选词同步完成，避免使用旧词组。
- 每次新的勾选操作有独立请求标识；同一次失败重试复用标识。响应丢失后再取消或重新勾选，不会误用旧请求结果。
- 失败保留勾选，并提供明确的重试入口；不宣称失败操作已保存。重新打开恢复已实际保存的选择。
- 移除单词时清理失效选词。阅读生成和交流仍使用真实的服务端校验、冻结任务与保存流程。
- 成功通知自动收起，撤销在页头仍然可用；通知不挡住分页或底部开始按钮。
- 导入和设置共用可访问弹窗：背景不可操作，Tab 焦点循环，Esc 关闭，关闭后返回入口。熟练度和行菜单使用独立浮层，避免列表边界裁切。
