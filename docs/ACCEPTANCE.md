## 尚需实际宿主完成的步骤

### ChatGPT Work 内置浏览器实测（2026-10-14）

已在当前 ChatGPT Work 对话的**内置浏览器插件宿主**里实际调用已关联的 `Test` MCP App。导入 `retain`、`compelling`、`diminish`，输入批次里重复的 `retain` 被合并；确认页显示 3 个新词、1 个批内重复，保存后词库显示 3 个词及撤销入口。模型通过当前订阅生成题为 “AI on Campus: Convenience and Intellectual Effort” 的 401 词文章；三个目标词各出现两次，服务端校验逐处映射后保存，MCP App 随即打开历史文章阅读页。点击 `compelling` 即展示该位置预存义项，没有重新生成；反馈“有点模糊”实际保存为熟练度 2，并显示“撤销上次操作”。截图视觉检查确认目标词轻提示与正文排版保留；当前内嵌容器下正文为单栏。

这次真实宿主结果是在 ChatGPT Work **内置浏览器**会话中；不是 ChatGPT 独立桌面 App，也不是平板 App。它补足了此前“宿主生成闭环未验证”的状态，但不补足桌面、平板、两端同步、真实 Voice 的验收。样例词、文章与反馈已真实留在项目数据库 `data/vocabulary.sqlite`，属于用户可见的学习数据；没有重复加入或重复生成同一文章。

按 [安装与使用说明](../README.md) 在账号 Plugins 中添加当前 HTTPS 服务，选择 OAuth/DCR，完成授权并取得实际技术 ID；需要组合包时运行 `bind-chatgpt.mjs` 绑定真实 ID。桌面本地 marketplace 已可发现，但不是已经在 ChatGPT 安装。

分别在目标桌面与平板完成：保存同一批真实单词、重新加入/撤销、点击生成观察宿主模型 validate/save 调用、打开同一文章和逐处释义、平板反馈后电脑刷新，以及服务停止/恢复。保留实际设备版本、文章/词条 ID 与真实结果。不能用本报告的尺寸、HTTP 客户端或 Codex 开发聊天替代。

## 日常限制与迁移

电脑须持续开机、联网，MCP 服务与安全连接须保持运行；临时转发没有 uptime 保证。停止/休眠后两端会暂时不能读写，已保存数据保留。恢复网络只需重新读取，不将未保存状态标成跨端同步。

所有模型工作仍消耗宿主订阅的正常使用额度；服务器不调用模型，不要求 API Key。当前没有付费服务。下一阶段固定地址与持续在线服务的费用需另行同意。业务备份保留所有学习 ID、历史与映射，排除 OAuth 凭据，迁移不重写产品。详见 [迁移说明](MIGRATION.md)。
